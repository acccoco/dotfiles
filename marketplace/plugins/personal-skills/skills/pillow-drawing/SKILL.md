# Pillow 绘图

## 工作流程

1. 从用户请求和已有上下文确定图片内容、用途、尺寸、背景及输出位置。只询问会影响结果的缺失信息；其余采用适合内容的尺寸和布局，并说明采用的默认值。未指定格式时输出 PNG。
2. 优先使用项目现有 Python 环境，检查能否导入 `PIL`。缺少 Pillow 时要求用户安装。

## 绘图风格

采用默认浅色主题的简洁编辑式风格：浅灰纸面、深色文字、细边框和充足留白，用少量强调色建立阅读重点。
| 角色 | 默认值 | 用途 |
| --- | --- | --- |
| `paper` | `#f5f5f5` | 画布和默认节点底色 |
| `paper-2` | `#ececec` | 必要的次级分区底色 |
| `ink` | `#2d3142` | 主文字和主要轮廓 |
| `muted` | `#4f5d75` | 次级文字和默认连接线 |
| `soft` | `#5a6580` | 辅助说明 |
| `rule` | `ink` 的 12% 不透明度 | 装饰分隔线 |
| `rule-solid` | `#bfc0c0` | 较明显的装饰边框 |
| `accent` | `#bf4520` | 重点节点、关键路径或关键结论 |
| `accent-tint` | `accent` 的 8% 不透明度 | 重点节点浅底色 |
| `link` | `#2e5aa8` | 有语义需要时的外部连接或 API 调用 |

- **突出重点**：同一张图通常只强调 1–2 个元素，其余使用中性色。强调色表示阅读重点，不自动代表错误或警告；不使用彩虹配色、霓虹发光或装饰性阴影。
- **背景与节点**：默认使用干净的 `paper` 背景，不加点阵、网格纹理或外层卡片边框。普通节点可用白底配深色细边，重点节点用 `accent-tint` 配 `accent` 边框；按内容层级区分节点，不把所有内容强塞入相同卡片。
- **几何与留白**：以 4px 为布局基准，位置、尺寸、间隔和内边距尽量对齐；节点间隔参考 20–48px，内边距参考 8–16px，节点圆角约 6px、分区圆角约 8px，常规线宽约 1px。数值按最终输出尺寸统一缩放；字体基线、数据坐标和线宽不强制吸附网格。细线和小圆角可通过高分辨率绘制后缩小获得平滑边缘。
- **文字层级**：通过标题、节点名、辅助说明的字号、字重与留白建立层级，保持短标签和易扫读的布局。字体仍遵循下节的中文黑体、英文等宽优先规则；不引入参考风格的 Web 字体，也不以缩小文字来掩盖内容过密。
- **关系图连接线**：默认使用 `muted`，重点路径可用 `accent`，可选或异步关系用虚线。优先水平、垂直及圆角直角折线，避开无关节点；并行线分开布置，共用节点边缘时使用不同连接点。先画连接线再画节点，线标签放在相邻空白处，与线保留约 6–10px 间隔，必要时用实际背景色遮罩；图例放在图形区外或底部。这些规则不限制数据曲线、几何图形本身的斜线。
- **控制密度**：删除不传递信息的边框、箭头和重复标签。关系图超过约 9 个节点或 12 条连线时，优先考虑总览与细节分图；不能为满足数量目标省略用户要求的信息。内容较少时直接留白，不补装饰节点或默认排列三张等宽总结卡片。
- **颜色与对比**：Pillow 中将半透明颜色先与实际背景合成，避免把低透明度色值直接当实色。普通文字与背景的对比度以至少 4.5:1、关键线条以至少 3:1 为目标；浅色装饰边框不能成为唯一的信息载体。重点浅底上的文字使用 `ink`，并检查实际合成后的可读性。

## 字体选择

用户指定的字体优先；

未指定时，中文优先使用黑体（如 `SimHei`、`Microsoft YaHei`、`PingFang SC`），英文优先使用等宽字体（如 `Consolas`、`Courier New`、`Menlo`）。混合文本中，中文和英文应尽量使用相同字号和行高，避免出现明显的视觉错位。

如果缺少必要的字体，提醒用户进行安装。
